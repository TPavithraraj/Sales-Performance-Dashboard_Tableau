# Global Retail Pvt Ltd | Sales, Product & Customer Insights Dashboard

## 📊 Project Overview

This project focuses on analyzing retail business data using Tableau to gain meaningful insights into sales performance, product trends, customer behavior, and regional performance.

I developed two interactive dashboards to transform raw retail data into meaningful business insights and support data-driven decision-making.

## 📌 Dashboards Created

### 1. Sales Overview Dashboard
- Total Sales, Total Orders, Total Profit and Profit Ratio.
- Sales Performance Analysis.
- Region-wise Sales Analysis.
- Category-wise Sales Performance.
- Actual vs Target Sales.
- Running Total Sales.

### 2. Product & Customer Insights Dashboard
- Total Products and Total Product Sales.
- Profit Ratio Analysis.
- Top N Products Analysis.
- Top Customer Sales.
- Product Category Performance.
- Sales Distribution Histogram.
- Customer Segmentation Analysis.

## 🛠️ Tools & Technologies Used

- Charts and Graphs
- Dashboard Navigation
